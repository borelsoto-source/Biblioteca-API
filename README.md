# 📚 Biblioteca API

API REST para gerenciamento de uma biblioteca.

## 🚀 Tecnologias

- Java 25
- Spring Boot
- Spring Data JPA
- Hibernate
- PostgreSQL
- Maven

## Funcionalidades

✅ Cadastro de autores  
✅ Cadastro de livros  
✅ Cadastro de usuários  
✅ Controle de empréstimos  
✅ Pesquisa por título, autor e gênero

## Arquitetura

Controller → Service → Repository → Database
